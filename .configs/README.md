# Configuration source examples

> **Inspection only — do not run or install anything from this repository.**
> Much of this project was built with **AI-Assisted Development workflows** to demonstrate and test logic.
> The code, configuration and documentation have not been independently verified and must not be trusted for correctness, security or reliability. Read them as untrusted illustrative material only.

The strict-JSON fragments illustrate ordered composition of editor and container configuration. Base, Python, TypeScript, Rust and Pact fragments describe different concerns; their combination is not a verified environment.

Do not activate the container fragments, lifecycle hooks or editor tasks. They can execute code and install dependencies. The existing host container file is separate from these examples.
