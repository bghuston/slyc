# Unverified contract artifacts

> **Inspection only — do not run or install anything from this repository.**
> Much of this project was built with **AI-Assisted Development workflows** to demonstrate and test logic.
> The code, configuration and documentation have not been independently verified and must not be trusted for correctness, security or reliability. Read them as untrusted illustrative material only.

The Pact-shaped files are hand-authored design fixtures, not generated or verified contracts. `verification/results.json` contains no evidence. A JSON validity label cannot establish Pact conformance or service compatibility.

`catalog.json` binds illustrative consumer-version labels to contract paths. The fixtures represent Checkout → Orders, Checkout → Payments and Orders → Inventory. Checkout → Payments revision 1.0 requires status; revision 1.1 does not. Scenario expectations are not observations.
